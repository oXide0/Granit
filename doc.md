## 4. Технічні вимоги

- **Framework:** Astro (останню стабільну версію використовувати за замовчуванням — переглянь актуальну документацію Astro, якщо є сумніви щодо API)
- **Стилі:** проста, легка CSS-система (Astro-компоненти зі scoped styles, або Tailwind — обери простіший варіант для мінімального бюджету; не додавай зайвих залежностей)
- **SEO:**
    - `<title>` та meta description українською, з акцентом на "камінь Житомир", "природний камінь Житомирська область", "вироби з каменю Коростишівський район" — підбирай природні формулювання, без переспаму ключами
    - Semantic HTML (`<header>`, `<main>`, `<section>`, `<footer>`)
    - Open Graph теги (og:title, og:description, og:image — навіть із плейсхолдер-зображенням)
    - `alt`-тексти для всіх зображень українською
- **Продуктивність:** статичні зображення оптимізувати (Astro `<Image />` компонент), lazy-loading для зображень нижче першого екрану
- **Форми:** форми зворотного зв'язку НЕ обов'язкові на MVP — основний CTA це дзвінок. Якщо додаєш форму — це має бути простий `mailto:` або статична форма без бекенду (мінімальний бюджет, без сервера)
- **Аналітика:** залиш місце/коментар у коді для підключення Google Analytics / Google Tag Manager пізніше (поки не підключай — немає підтвердження, що клієнт це хоче)
- **Домен/хостинг:** не є частиною цього репозиторію — налаштовується окремо
